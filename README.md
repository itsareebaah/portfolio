A responsive and animated personal portfolio built with HTML, CSS, JavaScript, and Bootstrap. Showcases your About, Skills, Projects, 
and Contact sections with smooth animations using CDN libraries. Perfect for beginners learning front-end development.

✨ Features

💻 Fully responsive for desktop & mobile

🎨 Animated sections using animation CDN libraries

📑 Sections included: About, Skills, Projects, Contact

🔗 Social media & project links integrated

⚡ Lightweight and easy to customize
